Debugger (CDP / response bodies) Unknown

Granted at install time. Required for response-body capture, network modification, and full DevTools control via debugger_attach / debugger_send. Chrome shows a yellow banner on the tab while attached. If you see "Not granted", reload the extension on chrome://extensions (the ⤴ button takes you there).

Workspace (virtual files)

A scratch filesystem the agent uses to store scraped data outside the conversation context (lives in IndexedDB — GB-scale quota, survives reloads). Tools: fs_write / fs_read / fs_append / fs_list / fs_zip. Slash: /ls, /zip, /clearfs.

—

Workspace folder (on disk)

Subfolder name that every file the agent saves to disk (ZIPs, chat exports, media_download, workspace_save) is placed under. Default downloads-mode writes to <Chrome's Downloads dir>/<folder>/. Documents-mode additionally moves each file to ~/Documents/<folder>/ after the browser finishes the download — requires the Shell bridge below.

Shell bridge (native messaging)

The shell_exec tool lets the agent run real shell commands on your machine via a small Python host installed under your home directory. Once installed, no sudo or open port is involved — Chrome speaks to it over stdio.

Skills hub

Domain-scoped playbook store the agent searches before tackling tasks and writes to once a /goal completes. Pre-configured to the public hub at skills.kryvik.com — works out of the box. Leave these fields untouched, paste your own AWS-deployed hub URL + key (from skills-hub/deploy.py) to point at a private hub, or type off into the URL field to disable the hub entirely.

AWS S3 (and S3-compatible)

Credentials for the s3_upload tool and the uploadToS3 option in media_download. Works with native AWS S3, Cloudflare R2, Wasabi, MinIO, Backblaze B2 (S3 API), etc.

Custom OpenAI-compatible providers

For Ollama / LM Studio / Groq / Together / Fireworks / Anthropic-via-proxy / Gemini-OAI etc. Base URL should be the path up to (but not including) /chat/completions. Examples: http://localhost:11434/v1 (Ollama), https://api.groq.com/openai/v1, https://generativelanguage.googleapis.com/v1beta/openai (Gemini). Leave API key empty for keyless local servers.

Custom slash commands

Use {{args}} as a placeholder for whatever the user types after the slash. Example name: tickets, template: Open https://jira.mycorp.com and find ticket {{args}}. Built-ins are listed under /help.

Custom JS tools

Define your own tools the agent can call. The code body runs in the side-panel context with full chrome.* and fetch access — treat as you would your own JS. args is the parsed input. Return the result; an exception becomes the tool error.

MCP servers

Each enabled server's tools/list is loaded on Save, registered under group mcp:<name> and offered to the model. JSON-RPC over HTTP (POST).

Backup

Exports a JSON file with provider keys, custom providers, MCP servers, slash commands, prefs. Import merges keys back. Sessions and memories are NOT included.
